# 宠物线上问诊小程序 · 开发需求文档 V0.2（骨架）

> **正式文档目标**：回填完成后，本文档应能直接支撑产品原型、接口设计、数据库设计与验收测试。
>
> 需求编号：`REQ-<域>-<序号>`。域：`TRIAGE` 分诊准入 / `REFER` 到院边界 / `SAFE` 安全兜底 / `RISK` 风险分级 / `INTAKE` 资料采集 / `VISION` 影像视频 AI / `AI-MAY` AI 可做 / `AI-MUSTNOT` AI 禁止 / `CHAT` 交互与介入 / `DOC` 医生工作台 / `RESULT` 处理结果 / `REFERRAL` 到院闭环 / `RECORD` 健康档案 / `KB` 知识库 / `USER` 客户建档与通知 / `OPS` 运营 / `MVP` 第一阶段 / `NFR` 非功能 / `DEC` 产品决策。

**目标**：建立宠物线上问诊小程序的开发需求基线，覆盖问诊流程、风险边界、AI 能力边界、影像辅助、医生效率与到院闭环。
